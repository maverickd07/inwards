二、核心发现：原任务上 context 训练精确修复"两步都会但组合错"的题（exp12）
基础模型分层（v3）；修复数为六种子均值。
  D303：gap(q1&q2 对) 41 题 → context 修复 15.3（37.4%），direct 2.8（6.9%）
         q1 错 36 题 → context 0，direct 0
         q2 错 21 题 → context 0.5，direct 0
         基础正确 205 题 → context 损失 5.5（2.7%），direct 0
  D500：gap 116 题 → context 29.8（25.7%），direct 4.3（3.7%）
         q1 错 69 题 → 0 / 0；q2 错 87 题 → 4.3 / 0.2
         基础正确 228 题 → context 损失 11.3（5.0%），direct 3.2（1.4%）
- 不用金标的指标：q1 答对的题中"组合答案 = 模型自己的 q2 答案"比例
  D500 基础 53.3%，context 61.2–62.9%（六种子），direct 53.1–55.3%。
解读：增益几乎全部落在"知识在、组合失败"的层；对缺知识的题无作用。这与"让模型用上已有知识"的设想一致。
主指标 +2.5pp 偏小，主要因为 gap 层只占 D303 的 13.5%（41/303）；按 gap 闭合率看是 37% 对 7%。
限制：分层由基础模型单次贪心输出定义，存在边界题回归均值；direct 对照的 7% 可视作这部分噪声的估计。D303 来自既往输出选择，非独立测试集。这不是内部机制的直接证据。

三、迁移失败的具体位置（exp13）
- MuSiQue 宽松口径 gap 题 64 道（官方 EM 口径 55 道）。其中第一跳关系为出生地/国籍/国家的题：0 道。
  第一跳关系为 author、performer、spouse、owned by、member of 等。
- 训练与原任务 D 集的桥接关系全部是"出生国"。因此 exp13 实际测的是"跨桥接关系类型"的迁移，而非同类桥接的跨数据集迁移。
- 在这 64 道题上：context 每种子修复 [5,5,4,4,5,5]（7.3%），direct 全部为 0。小但六种子方向一致。
- context 在 MuSiQue 上改动多：每种子真实修复约 7.8 题、EM 损失约 9.3 题（direct 约 1.2 / 3.2），净值接近 0。
- 错误类型：基础模型 85 题直接答出了第一跳实体（"停在桥上"）；context 把其中约 1/6 推离桥实体，但大多变成其他错误答案（426 次仍停在桥、81 次变成其他错误、3 次答对）。
- 部分损失可能来自参考答案的时效性（如加拿大保守党领袖 Andrew Scheer → 模型答 Erin O'Toole），未做人工裁决。

四、对"原因是什么"的当前判断（证据强度递减）
1. 方法在原任务上有效且作用位置正确：修复集中于 gap 层（强证据，上表）。
2. 迁移失败最可能的工程/设计原因：训练只覆盖一种桥接关系（出生国），适配器学到的可能是"先解析出生国"这一具体路由，而非通用组合。exp13 恰好不含这类桥（中等证据：结构性事实，加跨桥 7.3% vs 0% 的弱信号）。
3. context 训练改变模型幅度远大于 direct：404 题缓存 NLL，direct 目标在 direct 提示下 0.20，context 目标在 direct 提示下 3.28。direct 训练接近"学自己已经会说的话"，几乎没有梯度。因此 direct 不是等强度扰动对照；context 的部分改动（含 MuSiQue 上的损失）可能只是扰动（待检验）。
4. 评测分母：两个数据集中可修复的 gap 题都很少（41/303、55–64/1229），主指标被稀释。
