向内破：关于下一个范式的一点想法
陈威宇（Daniel Chen） Bocconi × HEC Paris weiyuchendaniel@gmail.com
先说几件我自己反复遇到的事。
做 DeepIV 弱工具变量诊断时（论文已投 ACM ICAIF 2026），我想到可以把 bootstrap 和全局敏感性分析放
在一起用。这两个东西模型都懂，我也让它帮我补了不少相关知识。但把两者拼成一套诊断工具的是我，不是
它。两块拼图都在它手里，它没想到要拼。
做浏览器 agent 时也一样。我想让 agent 的操作看起来像真人。模型知道人会停顿、会犹豫，可它加的停顿每
次都是同一个时长，最后是我自己写了个随机函数进去。它知道人不是机器，却还是用机器的方式去模仿人。
还有长项目里的 coding agent。我现在习惯在项目里给它留路标，因为它会忘掉自己早先读过的东西。
这些事让我相信：现在的模型缺的不是知识，是用知识的能力。知识它有，但调不出来，也不会组合。目前的
主流应对是继续 scaling，用更多参数和算力把更多情况直接覆盖掉。我觉得这更像暴力破解，只靠这条路走
不到 AGI。
向外破，向内破
现 在 说 的 “自 进 化”， 大 多 是 向 外 的： 在 环 境 里 试， 拿 奖 励， 改 自 己， 再 试。 问 题 是 向 外 破 没 有 底 线，
reward hacking 就是这么来的，模型会找任何能让分数变高的路，不管那条路对不对。我给 agent 留路标，
其实也是向外补，只是绕开了问题。
人学东西不全是这样。很多时候人是向内破的：回头看自己已经知道的东西，发现两件事之间原来有联系。我
觉得下一个范式应该让模型也能这样，审视自己的内部表征，把已有的知识重新组织起来，而不是一味往外要
更多数据。
这听起来可能有点玄，但做可解释性研究让我有一个体会：模型大，不等于看不懂。大模型里面也有能定位、
能读出来的结构。既然我们能读它，它就有可能读自己。第一步大概是让模型分清两件事：哪些知识它有但没
用上，哪些它是真的不知道。
我想先做的实验
先把这个缺口量出来。找一批任务，每个任务需要知识点 A 和 B，单独问 A、单独问 B 模型都能答对，但必须
把两者组合起来才能解决。看“都会”和“会用”之间差多少。
然后在同一个小模型上比两种办法。一种向外：加数据，或者用奖励做强化学习。一种向内：让模型基于自己
的表征反思、生成组合方案，再自蒸馏回参数。比三样东西：组合任务提升多少，旧能力忘掉多少，reward
hacking 出现多少。如果向内的办法用更少的数据做到差不多甚至更好，那“知识利用率”就是一个可以直接
优化的东西，而不只是 scaling 顺带的结果。
关于我
我在 BAINSA 做大模型机制可解释性，在 RoxyBrowser 做过 agent 自动化，也是 ACM ICAIF 2026 的审稿
人。之前有一位 VC 导师带我，我本来打算进 VC，也写过不少 AI 行业研究。VC 能让我坐在这个时代的前
排，但我想上台。
