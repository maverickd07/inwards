# 研究术语白话解释

不用一次背完。读笔记遇到词时回来查即可。

| 术语 | 白话解释 |
|---|---|
| 组合缺口 gap | 两步单独能答对，但合起来问就答错的那部分题。 |
| 桥实体 | 连接两步的中间对象。本项目通常是人物的出生国。 |
| 第一跳 Q1 | 先问人物出生在哪个国家。 |
| 第二跳 Q2 | 给定国家，问这个国家的首都、币种或其他属性。 |
| base 基础模型 | 还没接受本轮额外训练的原模型。 |
| context 带背景教师 | 先提供模型自己生成的出生国，再得到教师答案；不是说测试时一定给背景。 |
| direct 直接教师 | 直接回答组合问题得到的教师答案。 |
| self 自训练 | 把模型自己生成的目标拿来训练模型。 |
| gold 参考答案训练 | 用数据集参考答案作训练目标。参考答案本身也可能有歧义。 |
| target 训练目标 | 训练时希望模型输出的答案文字。 |
| adapter 或 LoRA | 附加在基础模型上的少量可训练参数，保存本轮学习变化。 |
| seed 种子 | 控制训练或抽样随机性的编号，用不同种子观察结果是否稳定。 |
| pp 百分点 | 从67%到70%是增加3个百分点。 |
| t95或95%区间 | 描述估计的不确定范围；需看它反映的是种子波动还是题目抽样。 |
| 区间跨零 | 当前数据不能清楚区分正效应、零效应或负效应；不等于已经证明没有作用。 |
| bootstrap | 重复重抽同一批题或人物，估计结果会波动多少。 |
| D500与fixed303 | 特定冻结题集的简称，不是实验分数。303已按历史输出选过，不能叫全新独立测试集。 |
| known313 | 按历史单步回答固定的313题，与303题有重叠，不是独立复现。 |
| matched785 | 用于匹配比较的785条训练题，不是785道全新测试题。 |
| EM 精确匹配 | 答案按规定规范化后，是否与参考答案完全一致。 |
| F1 | 按词语重合程度计分，可能与完整答对的趋势不同。 |
| logit lens 逻辑透镜 | 把每层隐藏状态投影成词语排名，观察哪些词能被读出来。 |
| probe 线性探针 | 额外训练一个简单分类器读隐藏状态中的信息；读得到不证明模型在使用。 |
| residual 隐藏残差 | 模型某一层保存的数值表示，不是自然语言笔记。 |
| token 词元 | 模型处理文字的片段；一个词或人名可能由多个词元组成。 |
| NLL | 模型给某段答案的负对数似然，越低表示在该提示下越容易生成这段文字。 |
| REVIEW | 自动规则无法可靠裁定、留待人工复核的答案。 |
| HISTORICAL | 识别为历史币种等过时答案，主分析按冻结规则处理。 |
| smoke 冒烟测试 | 用小样本或小模型检查程序能跑通，不是正式研究证据。 |
| HPC与Slurm | 远程计算集群与它的作业排队系统。 |
| job号 | 用户实际提交后产生的任务编号。 |
| SHA256 哈希 | 文件指纹，检查文件是否改变，不是模型分数。 |
| 预注册 | 看结果前写好预测、比较规则与停止条件，减少事后挑选解释。 |
| 因果证据 | 通过受控干预判断改变某个因素是否导致结果变化；相关或可读性本身不够。 |
