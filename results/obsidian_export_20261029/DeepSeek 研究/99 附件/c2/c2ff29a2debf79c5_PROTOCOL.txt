Scoring scope and policy
- Metric composed/q2: typed answer according to category. Metric q1: country.
- Whole-answer matching only. NFKC/case normalization; country/currency names
  also normalize accents, articles and minor punctuation. Explicit equivalent
  name groups are in aliases.json and apply to every item/model identically.
- Strip paired presentation quotes/backticks/bold and closed think sections;
  accept only fixed prefixes such as 'Answer:', 'The currency is', 'TLD:'.
  Do not extract favorable fragments from arbitrary explanation or negation.
- TLD: accept a whole label with optional boundary dot; IDNA equivalent labels
  normalized. Multiple distinct domains or explanatory prose cannot pass just
  because the correct TLD occurs in the text.
- Currency name, code and symbol remain different answer types. Do not accept
  a code when the requested answer is a symbol. Currency codes: complete three
  Latin letters. Symbols: preserve all punctuation and match the entire value.
  Thus Br is not matched inside Braille and B/. is not conflated with B$.
- ISO numeric country codes: complete 1..3 digits, zero-padding immaterial;
  reject fractional codes and signed telephone-code-looking answers. Coordinates
  retain the existing signed-floor rule; this D set contains no coordinates.
- Empty/wrong known answers get false. Unsupported prose, multiple answers or
  unknown name/symbol forms get false AND needs_review=true with reason. The
  conservative automated score counts only accepted, unambiguous answers.
  A review flag is not a human factual judgment. Report review counts by model
  and metric without dropping flagged items from the 500-item denominator.
- Aliases are deliberately finite; legitimate unlisted forms may be flagged.
  No general LLM semantic judge, substring fallback or gold-conditioned prose
  extraction. Mixed forms such as a name with parenthetical code are flagged
  unless they are explicitly an allowed complete alias. Do not claim this is
  a complete semantic/factual evaluation.
