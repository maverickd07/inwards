EXP11_ITERATE — protocol fixed 2026-10-05

Question: do refreshed self-generated targets improve unseen-person/unseen-family
composition across rounds, and does continuing weights outperform training more?
No gold target text, confidence filtering, evaluation-based allocation or best-round selection.

Data: identical exp8 train/eval identities. 216 training people, 4 categories/person,
864 questions. Original seed-7 three-person-partition: 72 people, 288 items/round.
Minimum requested 400 is not met; all 864 train questions are used every round.
Category counts per round: callingcode 216, capital 216, rounded_lat 216, rounded_lng 216.
A/B/C each fixed 500. Three independent training chains: seeds 0,1,2.
Gold used solely for diagnosis/scoring. Primary scorer: signed floor;
legacy and truncation retained as sensitivity analyses. No test-person leakage.

Base R0 freshly answers Q1 then answers composition with its OWN Q1 as context.
Targets cached once (not reused cached gold or gold-corrected Q1), frozen across seeds.
Generation: same exp8 question clarification and no-thinking chat prompt;
greedy max 24 new tokens. Mean raw-model log probability excludes special/EOS tokens.
Empty decoded targets are retained (no gold-dependent filtering); null confidence counted.

Shared R1: base + fresh LoRA, 2 epochs on R0 targets. Common to both branches.
RESET (primary): R2 and R3 each base + fresh LoRA; train only on previous RESET model targets.
CONTINUE: R2 loads R1 adapter; R3 loads CONTINUE R2 adapter; uses own previous model targets.
Optimizer and scheduler reset at each branch round. LoRA rank16 alpha32 dropout0.05,
AdamW lr1e-4 weight_decay0, batch8, warmup20 then linear decay, 2 epochs/round.
All stages isolated in fresh processes; model generation runs eval-mode, no dropout.
R3's own regenerated targets are diagnosed, but no R4 is trained.

FROZEN_BUDGET: independently start from base and R0 frozen targets, one continuous
training run of 4 epochs (R2 budget) or 6 epochs (R3 budget). Repetition is exposure,
NOT new unique data. Single-round frozen comparison for RESET is shared R1.
Control schedules decay across 4/6 epochs, whereas CONTINUE restarts schedules;
this residual optimization-schedule difference is explicit, not hidden.

Per seed: shared R1, RESET R2/R3, CONTINUE R2/R3, FROZEN_BUDGET R2/R3 = 7 fits.
Three seeds = 21 adapters. Each round: 864 unique items, 1728 exposures, 216 optimizer steps.
RESET final R3: 216 steps in its own weights; its full generating trajectory: 648 steps.
CONTINUE R3: 648 accumulated gradient steps in its weights.
Frozen 4/6-epoch controls: 432/648 steps, 3456/5184 exposures, 864 unique items.
All 21 fits combined: 6480 optimizer steps and 51840 sample exposures.
Model-target generation and evaluation wall-clock are logged separately from training.

Report ALL rounds: A/B/C composed, hop1/hop2 accuracy (all 500 questions), mean and
sample SD across seeds; generated target correctness + wrong-target confidence;
wrong-composed-answer mean log probability and intersection-of-errors confidence.
Confidence on a changing error set is conditional; it alone cannot establish escalation.

Primary C tests: 21 seed-wise model-versus-base McNemar tests plus 33 predeclared
between-condition/round seed-wise tests = 54, Holm corrected as one family.
Comparisons (3 seeds each): RESET R2/R1, RESET R3/R1, RESET R3/R2;
CONTINUE R2/R1, CONTINUE R3/R2; CONTINUE R2/frozen4, CONTINUE R3/frozen6;
RESET R2/frozen4, RESET R3/frozen6; RESET R2/CONTINUE R2, RESET R3/CONTINUE R3.
C single-hop baseline tests: separate 42-test Holm family.
Seed paired t95 intervals reported (n=3, normality assumption); no seed pooling.
A/B and target diagnostics exploratory. No new significance threshold chosen afterwards.
