1. Mac 本地终端（不是已经SSH登录的HPC窗口）：
scp "/Users/danielweiyuchen/Desktop/Deepseek-猜想实验/results/handoff_analysis_20261003/exp11_iterate/exp11_upload.tgz" 3355245@slogin.hpc.unibocconi.it:~/inward/

2. HPC SSH终端：
cd ~/inward
tar --keep-old-files -xzf exp11_upload.tgz && \
(cd results/handoff_analysis_20261003/exp11_iterate && sha256sum -c SHA256SUMS) && \
lquota && \
ls -lh results/handoff_analysis_20261003/exp11_iterate/run_exp11_iterate.sh

3. HPC提交（确保总排队+运行任务不超过2；本段只提交一个新任务）：
queued=$(squeue -h -u 3355245 | wc -l)
if [ "$queued" -lt 2 ]; then
  sbatch results/handoff_analysis_20261003/exp11_iterate/run_exp11_iterate.sh
else
  echo "已有至少2个任务，先不要提交exp11"
fi

4. 查看状态：
squeue -u 3355245
ls -dt results/handoff_analysis_20261003/exp11_iterate/runs_*
ls -t results/handoff_analysis_20261003/exp11_iterate/exp11-*.out

5. 把 JOBID 换成 sbatch 返回的实际数字：
sacct -j JOBID --format=JobID,State,ExitCode,Elapsed
tail -n 30 results/handoff_analysis_20261003/exp11_iterate/exp11-JOBID.out

6. 完成后只读结果：
cat results/handoff_analysis_20261003/exp11_iterate/runs_JOBID/analysis/report.txt
